# Settlement authority and presentation

All 827 world settlements register in the live settlement, office and trade
authorities. Detailed regional placement refines a settlement; its absence does
not remove world authority. The 33 records without detailed placement use their
existing integration economy and official profiles. Their compressed service
anchors come from the same generated physical interaction catalogue as party
origins and local services. These anchors are presentation, not invented authored
coordinates.

The shared generator emits capture eligibility, governance exceptions and military
projection policy separately. Capturable abstract settlements retain a stable core
record without spawning it or permanent defenses. Non-capturable communities
reject capture and do not require a core. Reconstruction and control changes pass
through the same projection predicate. Discovery/service markers and the existing
physical object budgets remain unchanged. Abstract status grants no trade access:
local eligible actors, loaded/party map agreement, discovery, war/blockade,
warehouse ownership or authored service entitlement, capacity and commit-time
control checks still apply.

Military snapshot v4 carries the policy for detached runtimes; installed scenario
definitions reconcile it before projection. V1–v3 remain supported. The generated
registration supplies missing legacy settlements and officials once, preserving
existing records, title, control, resources, deadlines and offices. Current saves
missing a required authority record reject. Definition reconciliation never uses
the mutable campaign being replaced as a source of defaults. Trade domain v3 adds
discovery persistence and deterministic legacy defaults; see
[LIVE_TRADE_SAVE.md](LIVE_TRADE_SAVE.md). Campaign envelopes remain version 8 with
schemas 1–8 supported.

The settlements census now compares compiled authority registrations directly
with the complete world identity set. A separate policy comparison checks actual
compiled policy call arguments against integration capture/governance and
representation definitions. Markets retain their compiled identity census. No
presentation exclusion can remove a required authority ID, and unused JSON or
comment markers cannot satisfy either compiled comparison.

`AbstractSettlementTests.wurst` executes generated African and Southeast Asian
records through registered local trade commands, changed control, governance
exception rejection, campaign codec reconstruction and legacy migration. Native
presence and representation creation are recorded. Python regressions enumerate
all 33 missing IDs, compare every authored ID with generated authority/markets,
verify object budgets and switch a framework fixture's presentation using only
content. The exact-artifact verifier retains all unrelated release blockers.
