# Map Source

`AgeOfSailWorld.w3x/` is the canonical unpacked Warcraft III folder-map input. Despite its suffix, it is a directory, not a generated MPQ archive. Wurst reads it without changing it and writes packaged output below `_build/`.

This folder is also the reusable physical-map source template and the explicit
bootstrap/runtime-validation map. `physical-maps.json` partitions authoritative
scenario content into generated map-local runtime payloads; this folder is not the
final whole-world map.

The current contents are deliberately minimal: stock flat Lordaeron terrain, one player start-location marker, no doodads, and placeholder lobby metadata. They establish a valid build input only; they do not decide final geography, navigation, settlements, or visual design.

Most Warcraft map structures are binary by format. In particular, `war3map.w3i`, `war3map.w3e`, `war3map.wpm`, `war3map.shd`, `war3map.doo`, and `war3mapUnits.doo` cannot be represented as native editable text while remaining a folder-map that Warcraft and Wurst can open. The W3I is locked to current format 33 and embeds the supported client version 3.0.0.24268; `tooling/forsaken_kingdom_map.py` independently parses the complete one-player/one-force layout and rejects legacy or zero-version metadata. The remaining stock binary components came from the folder-mode starter generated by the pinned Wurst 3.0 toolchain. `map-source.json` records the expected file set, while the repository validator checks their headers, dimensions, neutral placement counts, and metadata relationships deterministically. Lobby strings remain editable in `war3map.wts`.

Do not commit a packed `.w3x` file or `_build/`. Future terrain and object-data changes belong in this folder (or in deterministic source generators feeding it), and scenario/gameplay authority remains in `scenario/` and `wurst/`.
